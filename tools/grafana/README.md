# Grafana Metrics for h2diagent

## Prometheus

Use h2agent's [`prometheus-only.sh`](https://github.com/testillano/h2agent/blob/master/tools/grafana/prometheus-only.sh)
to scrape the metrics. Each peer runs two processes with their own scrape port,
so scrape **both** of them: the h2diagent port feeds this dashboard and the
h2agent port feeds the [h2agent dashboard](https://github.com/testillano/h2agent/blob/master/tools/grafana/grafana/provisioning/dashboards/h2a.json)
(traffic client/server panels, message sizes, process resources):

```bash
prometheus-only.sh 10274 10374 11274 11374   # gx-high-load: h2agent + h2diagent ports of both peers
```

Prometheus ports are derived from admin port: `admin + 2000` (h2agent) and
`admin + 3000` (h2diagent). For the examples:

| Example | Peer | Admin | Prometheus (h2agent) | Prometheus (h2diagent) |
|---------|------|-------|----------------------|------------------------|
| gx | pcrf-mock | 8274 | 10274 | 11274 |
| gx | pgw-sim | 8174 | 10174 | 11174 |
| gx-high-load | pcrf-load | 8374 | 10374 | 11374 |
| gx-high-load | pgw-load | 8274 | 10274 | 11274 |

The example peers do not set process names, so every h2agent reports
`source="h2agent"` and every h2diagent `source="h2diagent"`. Panels that may mix
several processes (e.g. process resources) show the scrape `instance` in the
legend to tell them apart.

## Dashboard

Import `h2diagent-dashboard.json` into Grafana.

Panels:
- **Overview**: Active server peers, client peer state, connection rate
- **Diameter Server (Inbound)**: Requests received / answers sent by command code
- **Diameter Client (Outbound)**: Requests sent / answers received, timeouts
- **Errors**: Unsent requests, cumulative errors (unsent, timeouts,
  uncorrelated), uncorrelated answers (dropped) and recovered answers (by
  end-to-end / cross-leg), outbound HTTP/2 responses by status (200/400/502/504),
  inbound 5012 answers generated by the gateway
- **Gateway Latency**: Throughput, pending requests, timeout rate
- **Process Resources**: Memory (RSS/virtual), CPU, file descriptors and threads
  of the h2diagent process

Variables: `$datasource`, `$source`, `$rate_interval`
